Cara Mengaktifkan Sistem Real
Dashboard ini saat ini berjalan dengan data simulasi. Untuk menerima pesanan real dari marketplace, kamu perlu menyiapkan beberapa komponen berikut.

1
Backend Server (WAJIB)
Frontend HTML ini tidak bisa langsung terima webhook dari marketplace karena alasan keamanan (CORS, port, dll). Kamu butuh server backend yang:
  • Menerima webhook POST dari Shopee/Tokopedia/TikTok
  • Menyimpan pesanan ke database (MySQL/PostgreSQL/MongoDB)
  • Menyediakan REST API untuk difetch oleh frontend ini
  • Mengirim notifikasi WA via Fonnte/Wablas/Twilio
Contoh tech stack:
Node.js + Express + MySQL + Socket.io
PHP (CodeIgniter/Laravel) + MySQL
Python (FastAPI/Flask) + PostgreSQL
2
Daftar API Marketplace
Daftarkan aplikasi di masing-masing platform untuk mendapat kredensial:
Shopee Open Platform
open.shopee.com — Partner Key, Secret, Shop ID
Tokopedia API
developer.tokopedia.com — App ID, Client Secret
TikTok Shop API
partner.tiktokshop.com — App Key, Secret
WA Provider
Fonnte.com / Wablas.com — API Key
3
Set Webhook URL di Marketplace
Di setiap dashboard developer marketplace, set URL webhook ke endpoint backend kamu:
Contoh endpoint backend:
POST https://api.kamu.com/webhook/shopee
POST https://api.kamu.com/webhook/tokopedia
POST https://api.kamu.com/webhook/tiktok
GET https://api.kamu.com/api/orders
GET https://api.kamu.com/api/orders/:id
POST https://api.kamu.com/api/orders/:id/status
4
Hubungkan Frontend ke Backend
Masukkan URL backend API di pengaturan. Frontend ini akan melakukan fetch() ke backend untuk ambil data pesanan real.
Backend harus mengembalikan JSON dengan format yang sesuai (lihat di bawah)
5
Format Response API yang Diharapkan
Backend kamu harus mengembalikan data dengan format JSON berikut: 
// GET /api/orders
{
  "success": true,
  "data": [
    {
      "id": "SHP123456",
      "pembeli": "Rina Susanti",
      "phone": "6281234567890",
      "produk": "Kaos Polos Premium",
      "marketplace": "Shopee",
      "qty": 2,
      "price": 75000,
      "total": 150000,
      "status": "baru",        // baru|proses|kirim|selesai|batal
      "waktu": 1700000000000,  // timestamp ms
      "kurir": null,           // null jika belum dikirim
      "resi": null
    }
  ]
}

// GET /api/stats
{
  "success": true,
  "data": {
    "hari_ini": 24,
    "belum_proses": 7,
    "dikirim": 12,
    "pendapatan": 3450000
  }
}

// POST /api/orders/:id/status
// Body: { "status": "proses" }
// Response: { "success": true }
6
Aktifkan Mode Live
Setelah backend berjalan dan URL sudah diisi, klik tombol di bawah untuk beralih dari mode demo ke mode live. Sistem akan:
  • Berhenti menggunakan data simulasi
  • Melakukan fetch ke backend API setiap 10 detik
  • Menampilkan pesanan real dari marketplace
  • Mengirim aksi (proses/kirim/selesai) ke backend
  • Menampilkan error jika backend tidak merespon
